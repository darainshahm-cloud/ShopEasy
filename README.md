## Project Theme
ShopEasy is a premium electronics and accessories store built as a responsive web assignment. The site includes a homepage, product catalog, shopping cart, and checkout flow using HTML, CSS, JavaScript, and jQuery.

## Completed Features
- Responsive homepage with branding, hero section, benefits, featured products, and FAQs
- Product catalog with search, category filter, sorting, and loading/error states
- Shopping cart with quantity controls, remove actions, subtotal, discount, and totals
- Checkout form with validation, inline error messages, and simulated order confirmation
- Shared product data with a local JSON file and cart persistence using localStorage
- Fully responsive design for mobile, tablet, and desktop layouts

## Project Files
- index.html — Home page
- products.html — Product catalog
- cart.html — Cart and checkout
- products.json — Product data source
- css/style.css — All responsive styling
- js/store.js — Product logic and required functions
- js/ui.js — jQuery DOM interactions and event handling

## Run Instructions
1. Open the project folder in VS Code.
2. Start Live Server for the root folder.
3. Open the generated local site in your browser.
4. Use the navigation links to move between Home, Products, and Cart pages.

## Notes
This project is for a classroom demo and does not process real payments or connect to a backend service.
